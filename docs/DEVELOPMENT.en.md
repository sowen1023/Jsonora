# Developing Jsonora

[简体中文](DEVELOPMENT.md) · English

Jsonora is a Chrome Manifest V3 extension. Its viewer UI uses Preact, TypeScript, and Vite. Parsing, formatting, the JSON model, and graph layout live in `src/core/`, independently of browser APIs.

## Environment and commands

You need npm and Node.js `^20.19.0` or `>=22.12.0` (required by the current Vite version).

```bash
npm ci
npm run dev        # Preview the UI in a regular browser; settings use localStorage
npm run typecheck
npm test
npm run icons      # Regenerate 16/32/48/128 PNG icons from code
npm run build      # Create the unpacked Chrome extension in dist/
npm run zip        # Build and package jsonora-<version>.zip
```

`npm run dev` does not provide the full extension environment. It cannot replace testing the content script, popup, context menu, and DevTools panel in Chrome. Follow the [pre-release checklist](RELEASING.en.md#pre-release-checklist) and load `dist/` for a complete test.

Run `npm run fixtures` to start local test pages. `tools/cdp-shot.mjs` can capture `/harness/auto`; `--width 1280 --height 800 --scale 1` produces a store-sized image. Review any screenshot by eye before using it in a store listing.

## Code map

| Directory | Responsibility |
| --- | --- |
| `src/core/` | Tolerant parsing, flattened tree model, highlighting, formatting, search, graph layout |
| `src/ui/` | Preact viewer, raw/tree/graph views, settings, and design tokens |
| `src/content/` | Page detection and Shadow DOM injection |
| `src/pages/` | Standalone viewer, popup, options, DevTools panel |
| `src/background/` | Manifest V3 service worker and context menu |
| `src/platform/` | Chrome API detection, settings storage, temporary cross-context data handoff |
| `tools/` | Icon generation, extension build, test pages, screenshot utilities |

The build has three passes: extension pages use ES modules; the content script and service worker are each bundled into a single classic script. The content script injects its own styles into a Shadow DOM rather than relying on the host page's CSS. The release package also includes Jsonora's MIT license and `THIRD_PARTY_NOTICES.txt`, generated from the lockfile for runtime dependencies.

## Changing the icon

The vector artwork is [`logo.svg`](logo.svg). The inline UI version is `BrandMark` in `src/ui/Icons.tsx`, and Chrome's PNG assets are generated by `tools/gen-icons.mjs`. Keep all three in sync, run `npm run icons`, and inspect at both 16px and 128px. Chrome manifests do not accept SVG icons.

## Before submitting a change

Run `npm run typecheck`, `npm test`, and `npm run build`. Changes to the content script or permissions also need verification in a real Chrome extension installation. Do not commit `dist/`, ZIP packages, user JSON, test credentials, or Chrome Web Store credentials. Update the relevant documentation when UI behavior or the release process changes.
