# 使用 Jsonora

简体中文 · [English](USAGE.en.md)

Jsonora 的主界面左侧始终是原始 JSON，右侧在图形和树形之间二选一。两侧可以分别收起，拖动中间的分隔线可调整宽度。

## 从这些场景开始

| 你想做什么 | 从哪里开始 |
| --- | --- |
| 阅读 API 返回的 JSON | 打开接口地址；Jsonora 检测到 JSON 响应后自动显示双栏查看器 |
| 查看普通网页里的 JSON 示例 | 点击页面右下角的「渲染」提示，就地展开符合条件的 `<pre>` 代码块 |
| 检查剪贴板里的 JSON | 在查看器中粘贴，或从扩展弹窗的「快速粘贴」打开 |
| 查看本地 `.json` | 使用「文件 → 打开文件」或将文件拖入查看器；`file://` 页面需要单独授权 |
| 调试请求响应 | 打开 Chrome DevTools 的 Jsonora 面板；面板只会看到打开之后发生的请求 |

## 原始 JSON 与编辑

左侧提供语法高亮、行号和对象/数组折叠。点击行号旁的小方框可收起对应层级，不会删除内容。「文件 → 编辑 JSON」打开可编辑版本；语法错误会在应用前提示。编辑器内可按 `⌘/Ctrl + Enter` 应用。

「文件」菜单还可以粘贴、复制和下载 JSON。复制和导出使用设置中的默认缩进。搜索框支持普通文本、正则表达式、区分大小写以及仅显示命中项。

## 图形与树形

「视图」菜单只负责选择右侧的图形或树形：

- 图形默认使用紧凑卡片：对象的直接字段收进一张卡片，嵌套对象通过连线展开。右上角按钮可切换成每项独立节点。
- 树形使用虚拟滚动，适合长 JSON。展开、折叠、选中与详情操作在两种视图中相互配合。
- 图形画布可拖拽平移、滚轮缩放，右下角有缩放和适应窗口按钮。点阵辅助网格默认关闭，可在图形面板右上角或设置里开启。

## 不严格的 JSON

解析器会尝试处理 XSSI 前缀、注释、尾随逗号、单引号字符串、JSONP 包装和每行一个 JSON 的 NDJSON/JSONL。无法恢复时会指出错误位置及附近文本。容错解析可能改变输入的表示方式；如果需要精确核对，请以原始输入为准。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 搜索 | `⌘/Ctrl + F` |
| 打开文件 | `⌘/Ctrl + O` |
| 编辑器内应用 | `⌘/Ctrl + Enter` |
| 全部展开 / 折叠 | `⌘/Ctrl + ⇧ + E` / `⌘/Ctrl + ⇧ + K` |
| 复制选中节点 JSON | `⌘/Ctrl + C`（未选中文本时） |
| 在树中移动 | `↑` / `↓`；用 `→` / `←` 展开或返回 |
| 展开或查看详情 | `Enter` / `Space` |
| 关闭搜索或弹层 | `Esc` |

## 设置与限制

设置中可切换中英文、明暗模式、VS Code 与 GitHub 系列配色、字段字体、字号、缩进、动画、自动换行和节点上限。图形默认紧凑、网格默认关闭。

大文档超过节点上限（默认 30 万）时，深层内容可能不会全部进入树模型；搜索和原始视图仍可使用。原始视图超过 2 万行会自动关闭换行以保持滚动流畅。Chrome 内置页面和 Chrome Web Store 页面不允许内容脚本运行，这是浏览器限制。
